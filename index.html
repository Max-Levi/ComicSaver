ComicSaver

batch image saver

Save every image from a comic page in one batch.

ComicSaver is a Chrome extension: one click on the page you're reading, thumbnails of every image, drop the ones you don't want, and the rest download in order — Chapter 7_001, Chapter 7_002…

Checking for the latest version…

Free. No account, no tracking. For Chrome and Edge.

Install it

  1. Download with the button above and unzip the file into a permanent folder — somewhere you'll keep it, since Chrome loads the extension from that folder.
  2. Type chrome://extensions into Chrome's address bar, turn on Developer mode (top right), click Load unpacked, and pick the folder.
  3. Pin ComicSaver to the toolbar, open any comic page, and click its icon.

Why the extension

  • Reads the live page you're on — no blocked requests, no workarounds.
  • Grabs full-size images, including lazy-loaded and srcset variants.
  • Files land in your Downloads folder, sequentially named per batch.

Already have it? Updating

  1. Download the new version above — if several zips are in Downloads, use the highest version number.
  2. Unzip it into your existing ComicSaver folder, saying yes when asked to overwrite. (Same folder, so your settings survive.)
  3. On chrome://extensions, click the reload ⟳ button on ComicSaver's card. Done when the update banner is gone.
ComicSaver keeps nothing and sends nothing anywhere — everything runs in your browser.
